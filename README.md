**Web-based MySQL database management system**

A full-stack application inspired by database management environments such as MySQL Workbench.

It includes:

* SQL editor with syntax highlighting and autocomplete
* Database and table explorer
* Automatic Entity-Relationship diagrams
* Visual database and table designer
* Visual SQL query builder
* Result-grid data editing
* Transactions and rollback
* Database backup and restoration
* Data export and conversion tools
* JWT authentication and email verification
* REST API
* Server-side security validation

**Stack:** `Node.js` · `Express` · `JavaScript` · `HTML` · `CSS` · `MySQL`
